## Notes
- 51 draws collected (draws 1924-1974), covering the full historical
  period available from this source (~180 days).

  and correctly skipped as duplicates.
- Run took approximately 70 minutes for 51 requests, due to slow
  response times from the source site - not a code issue, but worth
  noting as an observation.

  ## Pagination / navigation note
This source does not require pagination or year-by-year navigation.
Each draw has its own direct URL addressed by draw number
(?drawNo=N), so historical collection is done by iterating draw
numbers directly rather than paging through a list view.
